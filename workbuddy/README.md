# 张三 · 个人主页

由 **WorkBuddy** 独立开发的纯静态个人主页。采用暖纸感编辑设计风格，以墨绿、陶土橙和青柠绿为识别色，包含完整的中英文排版、原创 SVG 人物插画和响应式布局。

## 如何预览

无需 Node.js、npm、构建工具、API Key 或网络连接。

- **直接预览**：双击 `index.html`，使用最新版 Chrome 或 Edge 打开即可。
- **本地服务预览（可选）**：在本目录执行 `python -m http.server 8080`，然后访问 `http://localhost:8080`。

所有 CSS、JavaScript、图标与头像均为本地资源；没有字体、图片或脚本 CDN 依赖。

## 如何修改个人信息

### 1. 姓名、职位、邮箱、简介与当前状态

编辑 `js/data.js` 顶部的 `profile`：

- `name`：姓名，会同步到导航、首屏和页脚。
- `role`：职位，会显示在导航品牌区。
- `email`：联系邮箱，会同步到邮件链接与复制按钮。
- `availability`：首屏合作状态。
- `intro`：首屏一句话介绍。
- `about`：关于我段落，可增删段落。
- `current`：关于我中的当前状态。

首屏主标题「把复杂的技术，做成简单的体验。」位于 `index.html` 的 `#hero-title` 中；SEO 的 `title` 与 `meta description` 也位于该文件顶部。

### 2. 数据概览与兴趣方向

- `stats`：首屏三项数据概览。
- `interests`：关于我底部的兴趣标签。

两者均在 `js/data.js` 中。

### 3. 技能与工具箱

编辑 `js/data.js`：

- `skills`：技能名称、说明、熟练度（0–100）和对应工具。
- `toolbox`：底部工具标签。

### 4. 作品与站点

编辑 `js/data.js` 中的 `works` 数组。每个条目格式如下：

```js
{
  title: "个人博客",
  kind: "site",             // site = 站点；project = 项目
  desc: "记录技术文章与生活随笔",
  url: "https://blog.example.com",
  icon: "📝",              // 建议使用 emoji
  tags: ["博客"]
}
```

直接增删数组条目即可，类型数量、标签选项和筛选结果会自动更新。所有链接均在新标签页打开，并带有 `noopener noreferrer` 安全属性。

### 5. 经历时间线

编辑 `js/data.js` 中的 `experience`，每项包含：

- `period`：时间段。
- `role`：职位或教育经历。
- `organization`：公司、组织或学校。
- `description`：经历简介。
- `tags`：相关能力标签。

### 6. 博客文章

编辑 `js/data.js` 中的 `posts`，每项包含标题、ISO 日期、显示日期、分类和摘要。当前为静态演示列表，不依赖外部博客服务。

### 7. 社交链接

编辑 `js/data.js` 中的 `socials`，修改 `name` 和 `url` 即可。默认提供 GitHub、Twitter/X、B 站和知乎占位链接。

### 8. 主题色、字体与布局

编辑 `css/style.css`：

- 文件顶部 `:root`：浅色主题色板、字体、容器宽度和圆角。
- `html[data-theme="dark"]`：深色主题色板。
- `.work-card--tone-*`：六种作品卡片配色。
- 文件底部媒体查询：1100、900、700、480px 等响应式断点。

## 功能清单

- 固定导航、当前区块滚动高亮、阅读进度条。
- 桌面导航与移动端汉堡菜单，支持 Escape 关闭。
- 明暗主题默认跟随系统，手动选择通过 `localStorage` 记忆。
- 作品与站点统一展示，支持类型和标签组合筛选。
- 邮箱一键复制，提供成功或手动复制反馈。
- Intersection Observer 滚动入场、技能条动画与克制的悬停反馈。
- 尊重 `prefers-reduced-motion`，减少动态效果时直接呈现内容。
- 语义化区块、跳转主内容链接、键盘焦点、ARIA 状态与 SVG 头像说明。
- 375px、768px、1024px、1440px 响应式布局，无横向溢出。

## 设计思路

页面没有采用常见的渐变玻璃模板，而是将个人主页处理为一册数字杂志：大号中文黑体与衬线斜体形成对比，细线、编号和留白建立阅读秩序；首屏原创几何头像提供个人识别度，作品卡片用低饱和色块区分内容，深墨绿技能区和联系区形成节奏变化。明暗主题共享同一套视觉语言，而非简单反色。
